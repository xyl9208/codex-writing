## 0. 一句话定位

**主问题**：主动脉瘤与夹层的组织转录差异中，哪些能够在不同队列间重复、在明确的细胞类型内重复，哪些与病程或壁层位置相关，哪些主要依赖队列背景？

**不再声称**：两病"由根本不同的机制驱动"；"否定动脉瘤—夹层连续谱"；"确定疾病特异性治疗靶点"；AUC 0.92 作为核心证据；GSE318877 作为急性夹层的独立验证。

**拟定题目（英文）**：Cross-cohort reproducibility and cellular context of transcriptomic alterations in ascending aortic aneurysm and type A aortic dissection

**拟定题目（中文）**：升主动脉瘤与 A 型主动脉夹层转录组改变的跨队列可重复性及细胞类型背景

## 3. 已核实的 v2 主结果（统计层）

### 3.1 随机效应 meta 分析（`scripts/14_meta_rem.py`）

| 指标 | ATAA（4 队列） | TAAD（6 队列） |
|---|---|---|
| v2 共识基因（REM-FDR<0.05，方向一致 ≥75%，名义显著 ≥50%） | **171**（上 96 / 下 75） | **1,917**（上 1,100 / 下 817） |
| 与 v1（Stouffer）共识的交集 / 保留率 / Jaccard | 163 / 33% / 0.32 | 1,917 / 87% / 0.87 |
| HKSJ 共识（标准 / 修正） | 0 / 0 | 354 / 0 |
| 共识基因中 95% 预测区间不含 0 的比例 | 32% | 28% |
| LOCO：去掉任一队列后共识保留率 | 11%–84%（去 GSE26155 仅 11%） | 66%–81% |

解读：ATAA 共识对推断方法和队列组成都更敏感；HKSJ 在 k=4/6 时极保守，说明**小 k 下的显著性列表不应被读作精确数字**，主要结论应落在模块层面与效应区间。

### 3.2 队列数量不是不对称的原因（TAAD 4-of-6 子抽样，15 种组合，共享基因范围）

| 指标 | TAAD 任意 4 队列 | ATAA 4 队列 |
|---|---|---|
| 队列间一致性 ρ 中位数 | 0.38–0.57（中位 0.51） | 0.12 |
| 共识基因数（同一基因范围） | 1,305–1,992 | 165–170 |
| LOCO 最低保留率 | 0.37–0.55 | 0.11 |

解读：在相同队列数、相同基因范围与规则下，TAAD 的跨队列一致性仍远高于 ATAA；可以说"统计证据不对称"，但仍不等于"动脉瘤生物学更不稳定"（病因与对照异质性是备选解释）。

### 3.3 基因分类 v2（跨疾病差异检验为主）

| 类别 | 数目 | 含义 |
|---|---|---|
| TAAD_enriched（差异 FDR<0.05） | 183 | 夹层中改变显著大于动脉瘤 |
| TAAD_enriched_equivATAA | 595 | 同上，且动脉瘤中通过近零等效性 |
| TAAD_only_undetermined | 1,017 | 仅夹层显著，差异未确立 |
| ATAA_enriched / _equivTAAD | 13 / 21 | 动脉瘤中改变显著大于夹层 |
| ATAA_only_undetermined | 93 | 仅动脉瘤显著，差异未确立 |
| shared_concordant / shared_magnitude_differs | 27 / 2 | 两病同向 |
| discordant | 9 | 方向相反 |

全基因组 log2FC 相关 ρ=0.11；共识基因重叠 38（期望 27，P=0.015）。

### 3.4 GSE190635 纳入敏感性

纳入后 TAAD 共识由 1,917 降至 796（保留 41%），但合并效应量相关 ρ=0.987，共识基因 I² 中位数由 62% 升至 72%：纳入主要增加异质性、降低检出，不改变方向；跨疾病分类的类别结构保持。

### 3.5 通路层面稳定性

v2（z_rem）与 v1（Stouffer）排序的 GSEA NES 相关：ATAA 0.86、TAAD 0.97、差异排序 1.00。MYC 靶基因、mTORC1、E2F、DNA 修复、ROS、p53 仍是 TAAD 最强的差异程序；干扰素-α 反应、凝血、有丝分裂纺锤体仍偏向 ATAA。

最终主表（Table 2）每行一个模块，列为：

5. 壁层分布（GSE318877 腔侧−外膜侧梯度，夹层 vs 扩张）
6. 组成条件化后是否保持
7. **综合判定**：重复 / 部分重复 / 未重复 / 证据不足

判定规则（预先声明）：
- "跨队列重复"：bulk 合并 g 的 95% CI 不含 0 且 ≥50% 队列名义显著；
- "细胞类型内重复"：至少一种驻留细胞类型内患者级同向且置换 P<0.05；
- "跨已观察病程支持"：急性与亚急性/慢性同向（不要求慢性显著）；"急性阶段富集"：急性显著且慢性方向相反或接近 0；否则"证据不足"；
- 不将任何单一结构的阳性结果升级为"固有"或"因果"。

### 7.2 结论写法（预设）

> 在纳入的人类升主动脉组织转录组中，夹层相关的结构丢失（SMC 收缩、内皮、外膜成纤维程序）与急性应激（缺氧/糖酵解、氧化应激、MYC/核糖体生物合成、p53、固有炎症）程序具有较强的跨队列一致性，并在驻留细胞类型内得到支持；其中结构丢失程序在亚急性/慢性夹层中膜仍可见，而急性应激程序在该阶段未见富集。动脉瘤相关的干扰素/抗原呈递、淋巴细胞浸润与胶原重塑信号在动脉瘤队列中重复出现但更依赖队列背景，且在夹层组织中弱或缺失。两病共享 NF-κB/IL-6/缺氧与 SMC 钙处理基因下调的核心。这些结果描述的是不同的组织转录状态及其可重复性，不能推断发病顺序或因果；细胞数量变化、疾病特异性治疗靶点需要独立组织学与功能验证。

### 7.3 与 Adv Sci 2026 图谱的关系（讨论中写法）

收敛证据：其 ENO1 驱动的糖酵解 SMC 重编程与 MIF-巨噬细胞轴，对应本研究 TAAD 特异的缺氧/糖酵解模块（ENO1 +0.90、HK2 +1.87、PKM、LDHA、MIF +0.74，FDR 均 <1e-8），且本研究显示该轴在 ATAA 中缺失；其 FBN1⁺/MFAP5⁺ 成纤维细胞耗竭对应本研究 MFAP5（−1.26）与外膜成纤维模块下调。互补：该图谱未覆盖 ATAA 的干扰素/MHC-II 程序及两病正式对比。不作为独立验证（数据重叠；自测数据需申请）。
